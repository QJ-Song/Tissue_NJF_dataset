# Superseded: NJF Mechanism Diagnostics

This historical file name is retained for compatibility with older task notes and output paths.

The current project framing is documented in:

```text
docs/NJF_MECHANISM_DIAGNOSTICS.md
```

Current SOFA experiments are **mechanism diagnostics**, not final baselines or benchmarks. They are used to understand response-basis expressiveness, coefficient/state dependence, rollout drift, and what variables future NJF datasets must record.

Do not present the current simulation-only diagnostics as evidence that NJF outperforms existing deformation prediction models. Reviewer-facing model comparison should be a separate real phantom/tissue benchmark with calibrated actions, observed deformation, and appropriate SOTA deformation-model baselines.
